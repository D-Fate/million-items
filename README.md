# Коллекция

Приложение для поиска, выбора и упорядочивания элементов из списка с миллионом ID.
Frontend — Angular 22 с CDK Drag & Drop, backend — Express 5. Оба написаны на TypeScript.

## Запуск

Нужен Node.js 24.15+ в пределах ветки 24. Точная версия указана в `.nvmrc`.

```sh
npm ci
npm run dev
```

Интерфейс открывается на http://localhost:4200. Запросы `/api` проксируются на сервер с портом 3000.

Для запуска production-сборки:

```sh
npm run build
npm start
```

В этом режиме Express раздаёт интерфейс и API на http://localhost:3000. Порт меняется переменной `PORT`.

## Возможности

- Два списка: доступные и выбранные элементы. Исходные ID — от `1` до `1000000`.
- Поиск по подстроке и загрузка страниц по 20 элементов при прокрутке.
- Добавление собственного ID, выбор и снятие выбора.
- Изменение порядка выбранных элементов мышью или кнопками, в том числе при фильтрации.
- Восстановление выбора и порядка после обновления страницы; фильтры сбрасываются.

ID передаются строками, пробелы по краям удаляются. Допустимы значения длиной до 128 единиц UTF-16 без управляющих символов. Регистр учитывается: `abc` и `ABC`, как и `1` и `001`, — разные ID.

## Устройство

```text
client/     интерфейс Angular
server/     Express API, хранилище и очереди
shared/     общие типы запросов и ответов
tests/      unit, API и браузерные тесты
scripts/    нагрузочная проверка
docs/       описание API, тестирования и запуска
```

Исходный миллион ID представлен диапазоном. В памяти хранятся добавленные ID, множество выбранных значений и массив их порядка.

Чтения, выбор и сортировка обрабатываются пакетами раз в секунду, добавления — раз в 10 секунд. Планировщик выполняет операции последовательно и объединяет одинаковые ожидающие запросы. Запись отделяет предыдущие чтения от последующих. Размер очередей и время ожидания ограничены.

Пагинация использует курсор с версией состояния. После изменения данных старый курсор отклоняется, и клиент перечитывает список. При сортировке ID переносится относительно другого ID в полном списке, поэтому скрытые фильтром элементы сохраняются.

## Проверка

```sh
npm test
npm run typecheck
npm run build
npx playwright install chromium
npm run test:e2e
```

`npm run check` запускает тесты, production-сборку и E2E. Для него Chromium должен быть установлен заранее. Нагрузочная проверка запускается отдельно: `npm run test:load`.

## Ограничения

Состояние общее для всех пользователей и хранится в памяти одного процесса. Перезапуск сервера или деплой сбрасывает добавленные ID и выбор. Поэтому приложение запускается в одной реплике, без базы данных и авторизации.

Некэшированный поиск в худшем случае проходит весь диапазон. Перестановка выбранных элементов занимает O(S), где S — число выбранных ID. Загруженные страницы остаются в DOM; для длительной прокрутки большого числа строк нужна виртуализация.
