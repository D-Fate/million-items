# Тестирование

## Unit и API

```sh
npm test
```

Vitest проверяет хранилище, планировщик и HTTP API: пагинацию, фильтрацию, уникальность ID, выбор, сортировку, версии курсоров, интервалы очередей, дедупликацию и ограничения нагрузки. HTTP-тесты используют Supertest.

## Браузерные сценарии

```sh
npm run build
npx playwright install chromium
npm run test:e2e
```

На Linux при необходимости установите системные зависимости командой `npx playwright install --with-deps chromium`.

Playwright запускает Chromium и отдельный сервер на порту 3100. Проверяются прокрутка, выбор, восстановление после обновления, поиск, добавление и дубликаты, Drag & Drop при фильтрации, управление с клавиатуры, сетевые ошибки и мобильная ширина экрана.

Для ускорения E2E сервер использует интервалы 20/100 мс. Интервалы 1/10 секунд проверяются unit-тестами планировщика с управляемыми таймерами; в обычном приложении они не переключаются через переменные окружения.

## Нагрузочная проверка

```sh
npm run test:load
```

Скрипт запускает локальный сервер с миллионом ID и реальными интервалами очередей. Сценарии: 500 одинаковых чтений, 300 повторных выборов, 200 добавлений одного ID и 100 разных поисков без совпадений. После операций проверяется целостность данных.

Пул ограничен 100 соединениями. Число запросов в сценарии не означает такое же число одновременно открытых соединений. RSS включает и сервер, и генератор нагрузки; время ответа включает ожидание соединения в пуле. Результат локального запуска не характеризует производительность конкретного хостинга.

## CI

GitHub Actions выполняет проверку типов, unit/API-тесты, production-сборку и E2E. При ошибке сохраняется каталог `test-results` с материалами браузерных тестов.

Браузерные проверки ограничены Chromium. Docker, внешний прокси хостинга и длительные сессии с большим числом загруженных строк проверяются отдельно.
